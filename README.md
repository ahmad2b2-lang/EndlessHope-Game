# Square Head Encounter (لقاء ذي الرأس المربع)

A small Arabic, turn-based RPG mini-game. Player (a cartoon heroine in a red dress) has 30 seconds to beat a stickman with a blank black square head. He never attacks. He only walks closer, offering "deals" in speech clouds, until he reaches her, pats her head and hands her a paper.

- Commands: attack, spark, potion, run
- Optional letter shown on the enemy's head
- Epic looping soundtrack (Web Audio, no files) with a mute button
- Single file, no build step: open `index.html`

Enable GitHub Pages (Settings, Pages, deploy from `main` branch root) to play it online.
